## 👑 About BlackVail RP

**BlackVail RP** is an advanced FiveM Roleplay project built on the **QBCore Framework**.

The project focuses on creating a serious, immersive and optimized Roleplay environment combining custom systems, realistic economy mechanics, emergency services, jobs, businesses, vehicles, housing and criminal activities.
